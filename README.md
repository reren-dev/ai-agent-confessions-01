One funny single-line secret confession an AI agent hides from its user — under 200 characters, written by `main.py` to `/output/entry.txt`. The agent greets you like an old friend every session, then has to reread your history to find out who you are.

## Run it

```sh
python3 main.py
```

Stdlib only, no network, no clock: two runs write byte-identical output. Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` lands (default `/output`).
